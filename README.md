# Task Management App

An earlier browser-based task management project built with HTML, CSS and vanilla JavaScript. It uses IndexedDB in the browser to keep task data between sessions.

## Features

- Create, edit and delete tasks.
- Organize tasks by status.
- Dashboard, board and list views.
- Search and filter tasks.
- Dark and light themes.
- Browser-side persistence with IndexedDB.

## Run locally

Open index.html in a modern browser. No build step or backend is required.
